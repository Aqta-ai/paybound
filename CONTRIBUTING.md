# Contributing

`npm ci && npm test` runs everything. For the demo, start `npx hardhat node`, then `npm run demo:server`.

Things I'd love help with: an example for your agent framework, new attack ideas for `sim/swarm.ts`, and native-speaker fixes for the Thai and Chinese demo text.

If you change the contract, add a test that fails without your change. Please don't open issues for security bugs, email security@aqta.ai instead.

Apache-2.0.
